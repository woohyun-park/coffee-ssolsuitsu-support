개발·문의 운영: [@woohyun-park](https://github.com/woohyun-park)

게임 오류, 접근성 문제, 개인정보 처리 문의는 이 저장소의 **Issues**에서 접수합니다. GitHub 계정이 필요합니다. 현재 서비스는 출시 준비 중입니다.

문의할 때 발생 시각, 휴대폰 OS·토스앱 버전, 문제 화면과 재현 순서를 알려 주세요. 실명·연락처·방 인증 토큰·비공개 전략·타인의 이름은 게시하지 마세요. 캡처에서는 개인 정보를 가려 주세요.

게임에 저장한 본인 정보는 **설정 → 내 정보 삭제**에서 삭제할 수 있습니다. 공개 게시판에 개인 정보를 올려 삭제를 요청할 필요는 없습니다.

## 개인정보와 보존

게임은 별명, 방 자격, 준비·행동·판정 기록으로 진행합니다. 종료된 방은 24시간 보존 후 1분 주기로 정리합니다. 사용자 삭제 요청은 즉시 이름·개인 기록·자격에 적용하고, 진행 중인 게임에는 익명 좌석만 남깁니다. 운영 백업은 최대 7일 순환 보관하며 복원 시 독립 삭제 원장을 다시 적용합니다. 복원으로 인한 재노출을 막는 삭제 참조 원장은 암호화하여 8일 보관 후 정리합니다.

토스의 익명 사용자 키는 같은 계정의 기기에서 방을 복구하기 위한 기기 저장소 구분에만 사용하고 게임 서버로 전송하지 않습니다. 기기 저장 정보는 앱의 삭제 기능으로 함께 제거합니다.

이 공개 문의 저장소에 직접 게시한 내용은 GitHub의 정책과 공개 범위가 적용됩니다. 개인 정보는 올리지 마세요.

## 게임 정보

2~10명이 각각 휴대폰으로 참가하는 비공개 방 게임입니다. 크레딧은 한 게임마다 10개 지급되고 행동에 소비되며 구매·환금·송금 기능은 없습니다. 최종 선정된 사람이 커피를 사는 목적의 게임이며, 정책 개별 확인과 등급분류 및 실제 토스앱 테스트를 마치기 전까지 정식 출시 완료로 안내하지 않습니다.
